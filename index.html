Cola rápida final

Contagem de JOIN

  • Colunas = colunas(A) + colunas(B). Sempre, em qualquer join.
  • Linhas casadas: para cada valor da chave, multiplique nº de vezes em A × nº de vezes em B.
  • INNER = só casados · LEFT = casados + sobra esquerda · RIGHT = casados + sobra direita · FULL OUTER = casados + as duas sobras.
  • NULL = unknown → nunca casa, vira sobra do próprio lado.

Esqueleto que resolve quase toda query

SELECT colunas, FUNCAO(x)
FROM tabelaA a
JOIN tabelaB b ON a.fk = b.pk   -- liga pelas CHAVES
WHERE filtro_de_linha         -- filtra LINHAS
GROUP BY colunas             -- agrupa
HAVING FUNCAO(x) > n         -- filtra GRUPOS
ORDER BY coluna DESC        -- ordena
LIMIT n;                     -- top N
  • A ligação vai no ON (chave = chave) — nunca jogue no WHERE de qualquer jeito.
  • "o maior / mais caro / maior nota" → subconsulta com MAX(). "mais velho / menor" → MIN().
  • WHERE filtra linhas · HAVING filtra grupos (depois do GROUP BY).
  • "quantos"→COUNT · "total/soma"→SUM · "média"→AVG.
  • Pegadinha: NOT IN com NULL na subconsulta → retorna 0 linhas.
  • NUNCA esqueça o WHERE no UPDATE/DELETE.

Derivação MER → Lógico

  • Entidade forte → tabela; chave vira PK.
  • 1:N → PK do lado "1" vira FK no lado "N".
  • N:N → cria tabela associativa nova com as 2 PKs como FKs (juntas = PK); atributos do relacionamento entram nela.
  • Auto-relacionamento 1:N (supervisão) → FK na própria tabela apontando pra própria PK. Essa coluna é só FK, nunca PK.
  • Atributo multivalorado → tabela nova com a PK da origem (FK) + o atributo.

Normalização

  • 1FN: atributos atômicos e monovalorados (sem repetição). Resolve multivalorado.
  • 2FN: em 1FN e sem dependência parcial (nada depende só de parte da PK composta).
  • 3FN: em 2FN e sem dependência transitiva (atributo não-chave não determina outro não-chave).
  • São acumulativas. PK simples já está em 2FN.

Avançado (Aulas 11–13)

  • CROSS JOIN = produto cartesiano (N×M) = FROM T1, T2 sem WHERE.
  • NATURAL JOIN = junta sozinho pelas colunas de mesmo nome/tipo (sem ON).
  • VIEW = consulta salva (tabela virtual); apaga com DROP VIEW.
  • Transação: BEGIN → COMMIT (confirma) ou ROLLBACK (desfaz tudo). "Tudo ou nada".
  • Procedure/Function você chama; Trigger dispara sozinha num evento (INSERT/UPDATE/DELETE).
  • Trigger BEFORE pode cancelar/alterar a tupla; AFTER só vê o que já aconteceu.
  • Cursor = lê o resultado aos poucos (evita estourar memória). DECLARE = declara variáveis (PL/pgSQL).
  • SQL embutida (Java): Connection, Statement, DriverManager. ODBC: driver psqlODBC.
